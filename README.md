## ✨ Features

- **Interactive Phase Navigation:** A responsive sidebar (desktop) and bottom navigation bar (mobile) that seamlessly switches between academic phases without page reloads.
- **Dynamic Analytics Dashboard:** Integrated data visualizations using Chart.js to display task distribution and critical quality thresholds (e.g., Similarity Index limits).
- **Smart Image Modal UI:** A custom-built, dependency-free image modal that includes a loading spinner and a graceful fallback interface if an asset is missing.
- **Fully Responsive Layout:** Optimized for all screen sizes, featuring intelligent text scaling for ultra-small mobile devices.
- **Zero Heavy Frameworks:** Built with pure, semantic HTML, vanilla CSS, and standard JavaScript for lightning-fast load times.
